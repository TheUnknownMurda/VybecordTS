Features

Everything in one window

No web dashboard, no browser tab to keep open. Install it, play something, and it is already working.

Zero-setup detection

It reads the Windows media session — the same thing behind your volume-key overlay. Whatever publishes to it shows up, with nothing to configure.

Real-time synced lyrics

Millisecond-accurate scheduling, shown in the window and on your presence. Position is extrapolated between updates, so nothing stutters.

Your own lyrics library

Import your .lrc files and they always beat anything fetched online. Flag a bad match once and it is never reused.

Spotify ad filter

Your status clears during an ad break instead of announcing the advertiser, and the window says why the gap is there.

Player picker

Several things playing at once? Priority sorts it out on its own — or pin the presence to the one you actually mean.

History, stats & wrapped

A persistent log of what you played, session top tracks, and a wrapped-style summary over any range you pick. Last.fm scrobbling optional.

How it works

Three hops, no middleman

Nothing is uploaded and nothing is accounted for. The track never leaves your machine except as a name, looked up for cover art.

Source Windows media session Metadata, timeline and playback events, straight from the OS.
Vybecord Priority, cleanup, lyric timing Picks the player that matters, tidies the title, schedules every line.
Destination Discord, over local IPC The desktop app’s own pipe on your machine. No server in between.

Smooth, not polled

Players publish a timeline update only every few seconds — Spotify every 4.5. Each one becomes an anchor, position is extrapolated from it, and a resync every three seconds catches seeks nobody announced. That is why the progress bar climbs instead of sawtoothing.

Off the main thread

The media session addon runs on its own worker thread. Electron’s main thread is a single-threaded COM apartment, and WinRT’s session calls simply never return there. Its own apartment, its own thread, and the window stays responsive.

Optional

Two ways to go further

The window works on its own from the first track. Where these apply, they hand it things Windows cannot report.

Spicetify extension

For the Spotify desktop client
  • Spotify’s own timed lyrics — the client’s lyrics endpoint answers only from inside the client, which is exactly where this runs.
  • Track changes arrive as events, not on a poll, so the presence turns over the instant the song does.
  • Exact progress, with no delay to compensate for.
  • Artwork and every artist straight from Spotify — no catalogue lookup needed to find a cover.

One button in Settings installs it and applies Spicetify for you.

Browser extension

For music playing in a tab
  • Which site the tab is actually on. Windows reports every tab as the browser, so SoundCloud and YouTube arrive indistinguishable.
  • The canonical link to the track, so your presence points at the real thing.
  • Position read from the page’s own audio element, rather than inferred.
  • Live-stream uptime on Twitch and Kick.

Spotify web, YouTube and YouTube Music, SoundCloud, Bandcamp, Twitch and Kick — each with its own switch.

Lyrics

Four sources, first match wins

Tried in order, top to bottom. Yours always come first, and an offset control fixes the stubborn cases.

  1. Your local library

    Any .lrc file you imported, for that track.

  2. Local LRCLIB dump

    An optional offline database. Point Settings at it and matching never touches the network.

  3. An online race

    LRCLib, Netease and Musixmatch queried in parallel; the first good answer wins.

  4. YouTube captions

    The fallback for YouTube playback, when you enable it.

Wrong lyrics? One button blacklists that match for that track, permanently. Translation and romanisation for Japanese, Korean and Chinese are a switch away.

Ad filter

Your status should not run adverts

Spotify publishes no flag for an ad break. It swaps the media session’s metadata for the advertiser’s, which is how an unfiltered presence ends up announcing an energy drink as though it were a song.

Vybecord keys on duration, the one thing every ad has in common, and protects genuine short tracks by checking whether they belong to the album playing around them. An interlude does; an advert never does.

On by default, under Settings → Detection. While an ad plays, the window says so — so the gap in your status never looks like a bug.
