Bienvenue dans VybecordTS

Deux minutes pour tout brancher. Vous pourrez revenir sur cette page à tout moment.

1

Installer Tampermonkey

Obligatoire. C'est l'extension navigateur qui permet à VybecordTS de lire ce que vous écoutez sur Spotify Web, YouTube, SoundCloud, Bandcamp, Twitch et Kick. Installez-la dans le navigateur que vous utilisez pour écouter de la musique.

Détection en cours…
Chrome Firefox Edge Safari
2

Ajouter les scripts

Un clic par plateforme : Tampermonkey ouvre son écran d'installation, vous confirmez. Installez au moins celles que vous utilisez — chaque script s'annonce ici une fois en place, il faut donc revérifier après l'avoir ajouté.

Recharge la page pour laisser les scripts fraîchement installés se signaler.
Rien ne se passe au clic, ou le navigateur affiche du code au lieu de proposer l'installation ? Tampermonkey n'est pas encore actif : reprenez l'étape 1, puis revérifiez.
3

Spotify via Spicetify

Pour l'application de bureau Spotify. L'installeur s'en est peut-être déjà chargé — lancez Spotify et jouez un titre pour vérifier.

Extension Spicetify
Vérification…
Si la pastille reste grise alors que Spotify joue, installez l'extension à la main. Fermez Spotify, puis dans PowerShell : spicetify config extensions vybecord.js spicetify apply Le fichier vybecord.js se trouve dans le sous-dossier spicetify-extension de VybecordTS ; copiez-le d'abord dans %APPDATA%\spicetify\Extensions\.

Le navigateur Web Spotify, lui, est couvert par le script « Spotify » de l'étape 2.
